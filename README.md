# 我们俩 · 恋爱记录微信小程序

一个零依赖、可直接用微信开发者工具打开的原生微信小程序 MVP。

## 已实现

- 恋爱天数与纪念日倒计时
- 双人主页与最近动态
- 时光记录：新增文字、心情与日期
- 共同计划：新增、筛选、标记完成
- “我们”资料与关系统计
- 本地缓存持久化和演示数据

## 本地运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. 没有 AppID 时选择测试号；正式发布时修改 `project.config.json` 中的 `appid`。
4. 点击编译即可预览。

## 目录

```text
├── app.js / app.json / app.wxss
├── pages/
│   ├── home/       首页
│   ├── timeline/   时光
│   ├── plans/      计划
│   └── us/         我们
└── utils/store.js  本地数据层
```
